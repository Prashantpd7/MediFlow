# MediFlow 🚑

MediFlow is a hospital inventory and stock intelligence system built using
Snowflake and Streamlit.

## Features
- Hospital & NGO inventory tracking
- Critical stock alerts
- Medicine billing simulation
- Inventory heatmap
- Reorder recommendations
- Hospital ↔ Distribution Center request flow

## Tech Stack
- Snowflake (Database + Streamlit)
- Python (Streamlit)
- Snowflake Snowpark

## How to Run
1. Execute `MediFlow_Setup.sql` in Snowflake
2. Run Streamlit app inside Snowflake Projects
